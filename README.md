# 📺 koyeb-tv — محطة تلفزية على Koyeb بدون ffmpeg (nginx فقط)

محطة بث تلفزي حقيقية تعمل على مدار الساعة 24/7 بموارد خفيفة جداً، مبنية على **nginx فقط**:

| القناة | المصدر | التقنية |
|---|---|---|
| **قناتك الرئيسية** | ملفات MP4 الخاصة بك في مجلد `media/` | بث حي وهمي (Fake-Live) عبر وحدة `nginx-vod-module` — إعادة تغليف HLS فورية **بدون أي ترميز أو ffmpeg** |
| **قناة إعادة البث** | أي رابط HLS (m3u8) أو TS خارجي | تمرير عبر `proxy_pass` مع إعادة كتابة الروابط تلقائياً |

**الرابط الناتج** يعمل في كل شيء: VLC، تطبيقات IPTV (TiviMate، OTT Navigator، IPTV Smarters)، المتصفح (صفحة مشغل مدمجة)، ووسم `<video>` في Safari.

---

## 🧠 كيف تعمل بدون ffmpeg؟

وحدة `nginx-vod-module` تقرأ ملفات MP4 مباشرةً من القرص وتعيد تغليفها إلى مقاطع HLS لحظة الطلب — **لا فك ترميز ولا إعادة ترميز**، استهلاك معالج شبه معدوم، مثالي للخطة المجانية على Koyeb (0.1 vCPU / 512MB RAM / 2GB SSD).

سكربت بايثون خفيف (مكتبة النظام فقط) يحلّل مدة كل فيديو من ذرات MP4 مباشرة، ثم يبني «جدول قناة» حلقي لا نهائي يُجدَّد كل 15 ثانية — نفس خوارزمية المثال المرجعي في وحدة vod نفسها (`test/playlist.php`).

```
المشاهد ──► https://app-name.koyeb.app/live/main/index.m3u8
                        │
                nginx + vod-module
                ├─ /map/live/main  ← جدول القناة (يتجدد كل 15 ث، حلقة 24/7)
                └─ يقرأ media/*.mp4 ويعيد تغليفها إلى مقاطع .ts لحظياً
```

## ✅ المتطلبات

1. حساب على [Koyeb](https://app.koyeb.com) (الخطة المجانية تكفي).
2. حساب على [Docker Hub](https://hub.docker.com).
3. Docker مثبّت على جهازك (`docker --version`).
4. ملفات فيديو **MP4 بترميز H.264 (فيديو) + AAC (صوت)** — هذا هو الترميز القياسي لأغلب ملفات MP4 (الملفات من الهاتف وYouTube وبرامج المونتاج الافتراضية عادةً H.264/AAC). ملفات H.265/HEVC **غير مدعومة** في حاوية TS.

> 💡 للتحقق من الترميز بدون ffmpeg: افتح الملف في VLC ← أدوات ← معلومات الترميز (Codec info) وابحث عن `H264` و`MP4A`.

## 🚀 خطوات النشر (Docker Hub ← Koyeb)

### 1) ضع فيديوهاتك في مجلد `media/`

انسخ ملفات MP4 إلى `media/`. ستُعرض بالترتيب الأبجدي في حلقة مستمرة. يمكنك حذف ملف `media/README.txt` بعد قراءته.

> ⚠️ كلما زاد حجم الفيديوهات زاد وقت بناء الصورة ودفعها إلى Docker Hub. للبداية جرّب بعدة ملفات صغيرة، والحجم الإجمالي المنطقي حتى ~4-5GB.

### 2) ابنِ الصورة وادفعها إلى Docker Hub

```bash
cd koyeb-tv

# سجّل الدخول (أول مرة فقط)
docker login

# ابنِ الصورة — ضع اسم مستخدمك في Docker Hub مكان USERNAME
docker build -t USERNAME/koyeb-tv:latest .

# ادفعها
docker push USERNAME/koyeb-tv:latest
```

### 3) أنشئ الخدمة على Koyeb

1. ادخل إلى [app.koyeb.com](https://app.koyeb.com) ← زر **Create Service** (أو Create App ← Web Service).
2. اختر **Docker image** كمصدر النشر.
3. في حقل الصورة اكتب: `docker.io/USERNAME/koyeb-tv:latest` (أو `USERNAME/koyeb-tv:latest`) — الصورة عامة فلا تحتاج بيانات سجل خاصة.
4. **Instance**: اختر `Free`.
5. **Exposure / Ports**: منفذ `800`**0** بالبروتوكول `HTTP` (هذا هو المنفذ الذي يستمع عليه nginx؛ إن أردت منفذاً آخر غيّر متغير `PORT`).
6. **Health check**: الافتراضي TCP يكفي، والأفضل اختر HTTP واكتب المسار `/healthz`.
7. **Environment variables**: أضف ما تريد من الجدول أدناه (كلها اختيارية ما عدا أنها مضبوطة مسبقاً بقيم معقولة).
8. اضغط **Deploy** وانتظر دقيقة أو دقيقتين.

### 4) شاهد قناتك 🎉

عند اكتمال النشر ستحصل على رابط مثل `https://APP-NAME-ORG.koyeb.app`:

| ماذا تريد | الرابط |
|---|---|
| صفحة المشغل (من المتصفح) | `https://APP.koyeb.app/` |
| قناة ملفاتك (لأي مشغل IPTV / VLC) | `https://APP.koyeb.app/live/main/master.m3u8` |
| قائمة المقاطع مباشرة | `https://APP.koyeb.app/live/main/index.m3u8` |
| قناة إعادة البث | `https://APP.koyeb.app/restream/…` (انسخه من صفحة المشغل) |
| فحص الصحة | `https://APP.koyeb.app/healthz` |

**في VLC**: وسائط ← فتح بث شبكي ← الصق رابط `master.m3u8`.

## ⚙️ متغيرات البيئة (كلها اختيارية)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `8000` | منفذ nginx — طابِقه مع منفذ الخدمة في Koyeb |
| `CHANNEL_NAME` | `قناتي HD` | اسم القناة في صفحة المشغل |
| `SEGMENT_DURATION` | `10000` | مدة مقطع HLS بالمللي ثانية (10 ثوانٍ) |
| `LIVE_WINDOW` | `60000` | طول نافذة قائمة البث بالمللي ثانية (6 مقاطع) |
| `SCHEDULE_INTERVAL` | `15` | كل كم ثانية يُعاد توليد جدول القناة |
| `SCHEDULE_EPOCH_MS` | `1767225600000` | نقطة بداية الخط الزمني للقناة (2026-01-01). اتركها كما هي؛ ثباتها يجعل البث يتواصل من حيث توقف حتى بعد إعادة النشر |
| `RESTREAM_URL` | *(فارغ)* | رابط القناة الخارجية: m3u8 للـ HLS أو رابط `.ts` مباشر — اتركه فارغاً لتعطيل القناة |
| `RESTREAM_TYPE` | `auto` | `auto` / `hls` / `ts` |
| `RESTREAM_NAME` | `قناة خارجية (Restream)` | اسم القناة الخارجية في صفحة المشغل |

## 🔄 تحديث الفيديوهات أو الإعدادات

```bash
# بعد تغيير الملفات في media/ أو تعديل المتغيرات في Dockerfile:
docker build -t USERNAME/koyeb-tv:latest .
docker push USERNAME/koyeb-tv:latest
```

ثم في Koyeb: افتح الخدمة ← **Deploy** ← **Redeploy** (سيجلب الصورة الجديدة). التسلسل الزمني للبث لا ينكسر لأنه محسوب من `SCHEDULE_EPOCH_MS` الثابت.

## 🩹 استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| صفحة المشغل تقول «القناة غير متاحة» | لا توجد ملفات صالحة في `media/`. تأكد أنها MP4/H.264 (وليس HEVC) وأن امتدادها `.mp4` أو `.mov` أو `.m4v` |
| المقاطع تُحمّل ثم يتوقف البث | ملف واحد أو أكثر تالف — راجع سجل الحاوية في Koyeb (Deployments ← Logs)، فالجدول يطبع أسماء الملفات المستبعدة وسببها |
| القناة الخارجية 403/404 | المصدر يحجب إعادة البث (Hotlink protection) أو الرابط انتهت صلاحيته. جرّب رابطاً آخر |
| القناة الخارجية تعمل في المتصفح وليس في المشغل | بعض المصادر تشترط ترويسة Referer محددة — خارج نطاق nginx بدون كود إضافي |
| بطء في أول تشغيل | طبيعي: أول مقاطع تحتاج تحميلاً. المشغل يبدأ بعد 3 مقاطع تلقائياً |
| الخدمة «نائمة» أحياناً | الخطة المجانية قد تخمّد الخدمات عند عدم الاستخدام حسب سياسة Koyeb الحالية — أداة مراقبة خارجية (مثل UptimeRobot) ترسل ping كل 5 دقائق تُبقيها مستيقظة |

**لقراءة سجلات الحاوية**: Koyeb ← خدمتك ← تبويب **Runtime Logs** — سترى أسطر `[schedule]` التي توضح عدد المقاطع المقبولة والمستبعدة.

## 📁 بنية المشروع

```
koyeb-tv/
├── Dockerfile                    # بناء nginx 1.28 + nginx-vod-module (مرحلتان)
├── docker-compose.yml            # تشغيل محلي للتجربة
├── nginx/
│   └── nginx.conf.template       # إعدادات المحطة (تُستبدل متغيراتها عند الإقلاع)
├── scripts/
│   ├── entrypoint.sh             # تهيئة وإقلاع كل شيء
│   ├── build_schedule.py         # مولّد جدول القناة الحلقي 24/7 (بدون ffmpeg)
│   ├── mp4_info.py               # قارئ مدة/ترميز MP4 مباشرة من الذرات
│   └── restream_env.py           # محلل رابط القناة الخارجية
├── www/
│   └── index.html                # صفحة المشغل (hls.js، عربية RTL، وضع داكن)
└── media/                        # ⬅️ ضع ملفات MP4 هنا
```

## 🔐 ملاحظة أمنية

مسار `/map/` الداخلي (جداول البث) محمي بـ `internal` ولا يمكن فتحه من الخارج. جميع نقاط البث تعمل بلا مصادقة — إن أردت حماية قناتك بعملية أبسط أضف لاحقاً وحدة `secure_link` أو قاعدة `geo/allowlist` في nginx.conf.
